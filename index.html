Concept Car — autonomous driving function private repo

Two-wheeled electric vehicle that drives a closed course untethered. Plant model and control law developed in Simulink, sequencing as a Stateflow chart, deployed as generated embedded C on a SAMD21.

  • Motor characterised by measured sweep, dead band included, rather than datasheet values
  • Route as a state machine with relative targets, so one four-state cycle closes any polygon
  • Verification retrofitted as CI: static analysis plus a requirements traceability gate
  • Simulink
  • Stateflow
  • MATLAB
  • Embedded C
  • PID
  • Jenkins

The route is a state machine, not a script. A Stateflow chart issues velocity and rotation commands, waits on guards computed from encoder feedback, and advances — read directly out of the model, not redrawn from memory. Verification is the same idea applied to testing: three stages, each removing one simulation, so a failure stays attributable to a layer.
